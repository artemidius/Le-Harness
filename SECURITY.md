# Security policy

Please report suspected vulnerabilities privately through GitHub's security advisory interface. Do not include credentials, private repository content, or exploit details in a public issue.

Pre-release versions receive security fixes on a best-effort basis. The project does not yet make a production-readiness claim.

Include the affected version, impact, minimal reproduction, and suggested
mitigation when possible. Expect an acknowledgement within seven days. Do not
test reports against infrastructure or repositories you do not own.
