# Changelog

All notable changes to Le Harness are documented here.

## Unreleased

## 0.1.0-rc.1 - 2026-11-13

- Added a bounded, cancellable agent controller with versioned runtime events.
- Added Le Rust-backed Mistral streaming, model discovery, and Codestral FIM.
- Added confined repository tools, transactional edits, exact approvals, and
  native or Docker command execution.
- Added hybrid cloud/local routing, MCP stdio clients, context compaction, and
  repeatable edit-strategy fixtures.
- Added atomic session journals, safe continuation, and an interactive trace
  TUI.
- Added Rust 1.88 CI, adversarial and protocol integration tests, operator
  documentation, and cross-platform release automation.
